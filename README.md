# Telecom Customer Churn Analysis

## Project Overview
This project analyzes telecom customer churn using Power BI.

## Tools Used
- Power BI
- DAX
- Data Modeling
- Data Visualization

## Dashboard Pages

### Page 1 - Overview
KPIs, churn rate, contract analysis, and internet service analysis.

### Page 2 - Customer Demographics
Gender, senior citizen, partner, and dependents analysis.

### Page 3 - Services Analysis
Phone service, online security, tech support, backup, and device protection analysis.

### Page 4 - Revenue & Charges Analysis
Monthly charges, tenure, and revenue insights.

### Page 5 - Executive Summary
Key business findings and churn drivers.

## Key Insights
- Churn Rate: 26.54%
- Month-to-Month contracts have the highest churn.
- Fiber Optic customers show higher churn.
- Customers without Online Security and Tech Support are more likely to churn.
- Long-tenure customers have better retention.
